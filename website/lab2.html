ขั้นตอนที่ 1–2: สร้าง Agent ใน Copilot Studio

1

เปิด Copilot Studio

เปิด Browser ไปที่ https://copilotstudio.microsoft.com → Login → ตรวจสอบว่า Environment ถูกต้อง (มุมขวาบน)

หน้าจอเริ่มต้นสร้าง Agent ใหม่
2

สร้าง Agent ใหม่

กด "Create blank agent" → ใส่ชื่อ Agent เช่น "HR Policy Bot" → กด Create → รอ Agent ถูก Provision

หน้า Overview ของ Agent ที่สร้างใหม่ พร้อม Instructions เริ่มต้น
💡 Tip

ตรวจสอบ Model ที่เลือกไว้ในแท็บ Overview (ค่า Default มักเป็นรุ่นล่าสุด เช่น Claude Sonnet) — Model ที่แรงกว่าจะช่วยให้ Agent เข้าใจ Instructions ที่ซับซ้อนและสรุปคำตอบจาก Knowledge ได้แม่นยำกว่า โดยเฉพาะเมื่อ Knowledge มีหลายไฟล์

ขั้นตอนที่ 3–4: เพิ่ม Knowledge จากไฟล์

3

อัปโหลดไฟล์ PDF/Word

ไปที่แท็บ Knowledge → + Add knowledge → Upload files → เลือกไฟล์ที่เตรียมมา → กด Add

ไฟล์กำลังถูก Index — สถานะ Processing
⚠️ ระวัง

⏰ อย่า Navigate ออกจากหน้านี้ขณะรอ! ระบบกำลัง Index ไฟล์ ใช้เวลา 2–5 นาที

📌 หมายเหตุ

ไฟล์ที่ Upload ได้: PDF, Word (.docx), PowerPoint (.pptx), Excel (.xlsx), และไฟล์ Text — ขนาดไม่เกินไฟล์ละ 512 MB ดูตัวอย่างไฟล์และไอเดียการออกแบบ Knowledge สำหรับสอนได้ที่ course-materials/sample-files-for-participants/

4

รอ Status เป็น "Ready"

เมื่อ Index เสร็จ Status จะเปลี่ยนเป็น Ready — ตอนนี้ Agent พร้อมค้นข้อมูลจากไฟล์นี้แล้ว

Knowledge Source สถานะ Ready พร้อมใช้งาน
💡 Tip

คลิกเข้าไปที่ไฟล์แล้วตั้งค่าเป็น "Official" ได้ ถ้าเป็นเอกสารที่เชื่อถือได้ที่สุด — Agent จะให้น้ำหนักกับแหล่งข้อมูลนี้มากกว่าแหล่งอื่นเมื่อคำตอบขัดแย้งกัน

ขั้นตอนที่ 5–6: เพิ่ม Website และทดสอบ

5

เพิ่ม Knowledge จากเว็บไซต์

Knowledge → + Add knowledge → Public websites → ใส่ URL เช่น เว็บ Intranet หรือ FAQ ขององค์กร → Add to agent

Knowledge หลายแหล่งพร้อมใช้งานพร้อมกัน (ไฟล์ + เว็บ)
6

ปิด Web Search และปิด Ungrounded Responses แล้วทดสอบ

Overview → Web Search → Disabled → Save เพื่อไม่ให้ Agent เผลอตอบจากอินเทอร์เน็ตแทนที่จะตอบจาก Knowledge ที่เตรียมมา

จากนั้นไปที่ปุ่ม Settings (มุมขวาบน) → Generative AI → เลื่อนหาหัวข้อ Knowledge → ปิด Toggle "Allow ungrounded responses" → Save

Agent ตอบพร้อมอ้างอิงชื่อไฟล์ต้นทาง
💡 Tip

ดูที่ "Referenced sources" ใต้คำตอบ — ถ้ามีชื่อเอกสาร/URL แสดงว่า Agent ดึงข้อมูลจาก Knowledge จริง ไม่ได้เดาเอง

⚠️ ระวัง

การปิดทั้ง Web Search และ Allow ungrounded responses พร้อมกันคือคอมโบมาตรฐานที่ Microsoft แนะนำเพื่อลด Hallucination ให้มากที่สุด — ตั้งค่านี้ไว้ตั้งแต่ต้น เพราะ Lab 4 (Fallback Topic) จะใช้การตั้งค่านี้เป็นเงื่อนไขสำคัญ

🎉 สำเร็จแล้ว!

คุณมี RAG Agent ที่เชื่อมต่อ Knowledge ได้หลายแหล่งแล้ว! ขั้นตอนต่อไปคือทำให้ Agent ตอบได้ฉลาดและตรงประเด็นยิ่งขึ้นด้วย Prompt Engineering

⚠️ ข้อผิดพลาดที่พบบ่อย

  • Navigate ออกระหว่าง Knowledge กำลัง Index → ต้องอัปโหลดใหม่
  • ลืมปิด Web Search → Agent อาจตอบจากอินเทอร์เน็ตแทนที่จะตอบจาก Knowledge ที่ตั้งใจ
  • อัปโหลดไฟล์ที่มีแต่รูปภาพ (Scan) → ระบบอ่านข้อความไม่ได้ ต้องเป็นไฟล์ที่มีข้อความจริง

🎯 ลองประยุกต์ใช้กับงานคุณ

ตัวอย่าง: Warehouse Safety Bot ตอบคำถามความปลอดภัยจากไฟล์ Factory_Safety_Policy.pdf (ดูตัวอย่างไฟล์เต็มได้ที่ course-materials/sample-files-for-participants/)
  • ลองอัปโหลดเอกสารของแผนกตัวเอง 1 ไฟล์ แล้วถามคำถามที่มักถูกถามบ่อย
  • ถ้ามี SharePoint Site ลองกลับมาเพิ่มเป็น Knowledge Source หลังจบคอร์ส
