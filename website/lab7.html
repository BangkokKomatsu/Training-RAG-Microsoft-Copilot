🚀 Deploy to Microsoft Teams

Lab สุดท้าย! นำ Agent ที่สร้างมาทั้งวันไป Deploy ให้ทีมงานใช้งานได้จริงผ่าน Microsoft Teams

Level100
PersonaMaker ที่พร้อมนำ Agent ไปใช้งานจริง
ระยะเวลา15 นาที
เป้าหมายPublish และ Deploy Agent ไปยัง Microsoft Teams ให้ทีมใช้งานได้ทันที

ขั้นตอนที่ 1–2: Publish และเปิด Channel

1

กด Publish

กด Publish มุมขวาบน → ยืนยัน → รอ Status เป็น Published

Agent ถูก Publish สำเร็จ
2

ไปที่ Channels

กด Channels ในแถบนำทาง → เลือก "Microsoft 365 and Microsoft Teams"

ตัวเลือก Channels ที่ Deploy ได้
💡 Tip

ก่อน Deploy ให้เปิดแท็บใหม่แล้ว Login เข้า Teams (Web) ไว้ล่วงหน้า — ป้องกันไม่ให้ขั้นตอน Login มาขัดจังหวะตอนที่กำลังทดสอบ Agent ใน Teams ช่วงท้าย Lab

📌 หมายเหตุ

นอกจาก Teams แล้ว Copilot Studio ยังรองรับ Channel อื่นอีกมาก เช่น Web app แบบฝังในเว็บ, Native app (iOS/Android), Email, Facebook, WhatsApp, Line — เลือก Deploy ไปที่ Channel ที่ผู้ใช้งานจริงอยู่แล้ว ไม่ใช่บังคับให้ผู้ใช้มาเรียนรู้เครื่องมือใหม่

ขั้นตอนที่ 3–4: เปิดใช้งานใน Teams

3

ติ๊ก Make available in M365 Copilot

ในหน้า Channel Panel → ติ๊ก Checkbox นี้ → กด Save จากนั้นกด "See agent in Teams"

เปิดใช้งาน Agent ใน Microsoft 365 Copilot
4

เพิ่ม Agent ใน Teams

Browser จะเปิด Teams Web ให้อัตโนมัติ → กด Add เพื่อเพิ่ม Agent เข้าบัญชี Teams ของคุณ

หน้าต่างยืนยันเพิ่ม Agent ใน Teams
💡 Tip

ถ้า Teams ถามว่าจะเปิด Desktop App หรือไม่ ให้เลือก "Use the web app instead" เพื่อความรวดเร็ว

ขั้นตอนที่ 5: ทดสอบใน Teams จริง

5

พิมพ์คำถามทดสอบใน Teams

ลองพิมพ์คำถามใน Teams Chat กับ Agent เปรียบเทียบ User Experience กับ Test Panel ใน Copilot Studio

Agent ตอบคำถามใน Microsoft Teams จริง
ตัวอย่างแบบเดียวกัน แต่คนละแผนก: Sales Data Bot ของทีม Sales Engineer ใน Teams — ตอบยอดขายเจาะจงจุดเดียวได้ถูกต้อง (ลองคำถามรวมยอดข้ามเดือน/สาขาดูด้วย จะเห็นข้อจำกัดของ RAG ตามที่คุยกันใน Lab 5)
📋 ตัวอย่างข้อความทดสอบใน Teams — Copy ไปวางถามได้เลย 
ยอดขายรถ Forklift ใหม่ของสาขากรุงเทพเดือนมกราคม 2568 เท่าไหร่?
⚠️ ก่อนใช้งานจริงในองค์กร (Production)

Lab นี้ Deploy แบบง่ายสุดสำหรับการเรียนรู้ ก่อนปล่อยให้ทั้งองค์กรใช้จริง ควรกลับมาตรวจสอบเพิ่มเติม: ตั้งค่า Authentication ให้เหมาะกับความละเอียดอ่อนของข้อมูล, จำกัด Domain ที่อนุญาตให้ฝัง Agent (สำหรับ Web channel), และทดสอบ Agent บนทุก Channel ที่ Deploy จริง เพราะ Feature บาง UI อาจแสดงผลต่างกันระหว่าง Test Pane กับ Teams

🎉 สำเร็จแล้ว!

🎉 ยินดีด้วย! Agent ของคุณพร้อมให้ทีมใช้งานจริงผ่าน Microsoft Teams แล้ว — คุณสร้าง RAG Agent ตั้งแต่ต้นจนถึง Production ได้ภายในวันเดียว!

⚠️ ข้อผิดพลาดที่พบบ่อย

  • ลืมกด Publish ก่อน → Channel จะยังใช้ Agent เวอร์ชันเก่าอยู่
  • App Policy ขององค์กรปิดอยู่ → ต้องติดต่อ IT Admin ให้เปิด Teams App Policy
  • ทดสอบใน Test Pane ผ่านแล้วไม่ทดสอบซ้ำใน Teams → บาง Feature อาจแสดงผลต่างกัน

🗺️ ก้าวต่อไปหลังจบคอร์ส

  • Live Data RAG: เชื่อม Agent กับ Database แบบ Real-time ด้วย MCP Server (Dataverse, ServiceNow)
  • Multi-Agent: สร้าง Agent หลายตัวที่ทำงานร่วมกัน แบ่งความเชี่ยวชาญตามแผนก
  • Autonomous Agent: Agent ที่ทำงานอัตโนมัติตามเวลา ไม่ต้องรอคนถาม
